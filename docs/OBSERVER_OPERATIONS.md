# Scoped support observer authority
Founder-managed observer grants use canonical role SPACECASE_SUPPORT_OBSERVER and SUPPORT_OPERATOR school membership. They never grant TEACHER, administrator or founder privileges. Grants require an active registered account without current learner membership, expire in 1–30 days and are audited. Renewing ends prior active grants. Revocation ends the selected assignment; retained canonical membership alone confers no authority.
Support context exposes observerSchools separately from school educator/admin access. Both active membership and current school-scoped role are required; global observer roles, inactive schools/persons, ended memberships, expired roles and learner memberships grant no observer scope. Portfolios over 200 schools fail closed pending a paginated authority contract.
This milestone provisions no real staff and sends no invitations. The founder verifies identity, eligibility and purpose before granting access. SpaceCase consumes this versioned context over HTTP and exposes read-only ticket metadata only. Ticket narratives and learner records require a separate future access workflow.
Acceptance: school admins cannot grant observers; observer roles cannot use founder endpoints; expiry, revocation and membership termination remove subsequent access. CI must pass before release. No schema migration is needed: existing canonical roles, memberships, assignments and audit tables are reused.

## Support-agent extension
The founder may explicitly choose AGENT instead of the default OBSERVER when granting access. AGENT creates SPACECASE_SUPPORT_AGENT authority for the selected school, with the same eligibility, membership, expiry and revocation checks. Agent schools are exposed separately as agentSchools and also participate in metadata monitoring. Existing observer grants remain read-only. Revoking an agent grant does not revoke an independent observer grant, and vice versa.
The management list returns eligible agents separately and excludes inactive accounts/persons, ended memberships and current learners. SpaceCase uses that fresh list when assigning cases. No agent permissions are added to school teacher/admin roles. These changes reuse canonical tables and need no PEOS schema migration.
